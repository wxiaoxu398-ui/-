# 原接口之外的扩展

- `POST /api/documents/upload`：multipart 字段 `file`，上传 PDF，拒绝覆盖同名文件。
- `PATCH /api/documents/{id}`：`title`、`author`、`source`、`license`、`source_url`。
- `GET/HEAD /api/documents/{id}/file?hash=...`：只读取 books 目录内的原 PDF，指纹不匹配返回 409；浏览器 `#page=N` 定位物理页。
- `GET/POST /api/settings`：返回配置状态，永不返回密钥。空 `api_key` 保留现值，`clear_api_key=true` 才清除。
- `GET /api/evaluation/questions`：20 题模板。
- `POST /api/evaluation/run`：接受 `question_ids` 和 `document_ids`；通过 SSE 返回 `result` / `done`，不创建普通聊天会话。

health 扩展字段含回答模式、检索后端、就绪数量、版本和索引任务状态；documents 列表包含任务进度和错误。

chat `meta` 含 `mode`；`done.finish_reason` 为 `stop`、`refused`、`cancelled` 或 `error`，附实际首段和总耗时。生成采用逐段引用检查，会比不检查的逐 token 转发增加等待；性能需要真实 API 测量。

生成断流或停止时保存已经发出的内容并标记状态；重启恢复上次中断状态。原文摘录模式是单独标注的无密钥功能。

原文保留按页边界，不跨页混合；页边缘清理仅处理高频短行。当前未实现复杂表格版式识别，也未实现 OCR；复杂排版需人工检查解析结果。
