# MedRAG 需求与实现对应

项目：面向医学生的本地医学教材 RAG 学习助手。只根据导入 PDF 回答，引用可追溯，资料不足拒答。

| 需求 | 实现入口 |
| --- | --- |
| F1 文档扫描、信息、重建 | 左侧文档库；`/api/documents` 与 `/api/documents/ingest` |
| F2 流式问答、编号、片段 | `/api/chat/stream`；中栏聊天与右栏来源 |
| F3 低相关拒答 | `backend/app/rag/retrieve.py` 与 `generate.py` |
| F4 固定免责声明 | 页面顶部固定横幅 |
| F5 会话历史、切换、删除 | SQLite；`/api/conversations` |
| F6 多轮追问 | 最近三轮上下文；简短追问扩展检索词 |
| F7 反馈 | `/api/feedback`；覆盖更新，刷新保留 |
| F8 停止 | AbortController；后端 finally 保存部分内容 |
| F9 Markdown | 安全关闭 HTML，引用文本转换为可点击按钮 |
| F10 纯 LLM 对比（可选） | 尚未实现 |
| F11 20 题评估（可选） | 左侧质量评估；结果需人工核验 |
| F12 文档筛选（可选） | 文档行勾选范围，支持选空后拒答 |

左栏 260px、中栏弹性、右栏 320px；窄屏转为可展开侧栏。

不含用户注册、登录、公网部署、患者数据、医学影像、临床决策支持。

验收目标包括三本真实医学 PDF、10 个教材内问题引用页码正确率 ≥80%、三个教材外问题拒答、多轮语义、刷新历史、无无来源自述。真实教材和 API 验收仍需要用户导入材料并配置密钥。测试夹具通过不替代真实医学验收。
