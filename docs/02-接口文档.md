# MedRAG 接口文档（API Spec）

## 1. 通用约定

- Base URL：`http://127.0.0.1:8000`
- 接口前缀：`/api`
- 编码：UTF-8
- 数据格式：JSON（SSE 接口除外）
- 时间格式：ISO 8601 字符串，例如 `2025-01-01T10:00:00`
- CORS：允许 `http://localhost:5173`

### 1.1 统一错误格式

```json
{
  "error": {
    "code": "DOC_NOT_FOUND",
    "message": "文档不存在"
  }
}
```

### 1.2 状态码约定

| 状态码 | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数错误 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 2. 数据模型

### 2.1 Document（文档）

```json
{
  "id": 1,
  "title": "生理学（第9版）",
  "author": "人民卫生出版社",
  "source": "OpenStax",
  "license": "CC BY 4.0",
  "file_name": "physiology.pdf",
  "num_pages": 520,
  "num_chunks": 1840,
  "status": "ready",
  "created_at": "2025-01-01T10:00:00"
}
```

`status` 取值：

| 值 | 含义 |
|---|---|
| pending | 待处理 |
| processing | 处理中 |
| ready | 已就绪 |
| failed | 处理失败 |

### 2.2 Source（引用来源）

```json
{
  "index": 1,
  "chunk_id": 1024,
  "document_id": 1,
  "title": "生理学（第9版）",
  "page_start": 112,
  "page_end": 113,
  "content": "心肌细胞的动作电位分为...",
  "score": 0.87
}
```

字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| index | int | 引用编号，对应答案里的 [1][2] |
| chunk_id | int | 切块 ID |
| document_id | int | 所属文档 ID |
| title | string | 书名 |
| page_start | int | 起始页码 |
| page_end | int | 结束页码 |
| content | string | 原文片段 |
| score | float | 相关度分数，0～1 |

### 2.3 Message（消息）

```json
{
  "id": 10,
  "conversation_id": 3,
  "role": "assistant",
  "content": "心肌细胞动作电位分为5期[1]...",
  "sources": [],
  "created_at": "2025-01-01T10:00:00"
}
```

`role` 取值：`user` / `assistant`

`sources` 为 `Source` 数组；用户消息时为空数组。

### 2.4 Conversation（会话）

```json
{
  "id": 3,
  "title": "心肌动作电位",
  "created_at": "2025-01-01T10:00:00",
  "updated_at": "2025-01-01T10:05:00"
}
```

### 3.5 流式问答（核心接口）

**POST** `/api/chat/stream`

请求头：

```
Content-Type: application/json
Accept: text/event-stream
```

请求体：

```json
{
  "conversation_id": 3,
  "question": "心肌细胞动作电位分几期？",
  "document_ids": [1, 2],
  "top_k": 6
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| conversation_id | int \| null | 否 | 为 null 表示新建会话 |
| question | string | 是 | 用户问题 |
| document_ids | int[] \| null | 否 | 为 null 表示全部文档 |
| top_k | int | 否 | 默认 6，返回引用条数 |

#### SSE 事件序列

**1）meta — 会话信息**

```
event: meta
data: {"conversation_id": 3, "message_id": 11}
```

**2）sources — 引用来源（生成前先推送）**

```
event: sources
data: {"sources": []}
```

**3）delta — 增量内容**

```
event: delta
data: {"content": "心肌细胞"}
```

**4）done — 结束**

```
event: done
data: {"message_id": 11, "finish_reason": "stop"}
```

**5）error — 错误**

```
event: error
data: {"code": "LLM_ERROR", "message": "模型调用失败"}
```

#### 前端处理逻辑

1. 收到 `meta` → 记录 `conversation_id` 和 `message_id`
2. 收到 `sources` → 渲染右侧来源面板
3. 收到 `delta` → 追加到当前消息气泡
4. 收到 `done` → 结束 loading，保存消息
5. 收到 `error` → 显示错误提示，结束 loading

## 4. 前端调用示例（TypeScript）

### 4.1 SSE 流式问答

```ts
export interface ChatRequest {
  conversation_id: number | null;
  question: string;
  document_ids?: number[] | null;
  top_k?: number;
}

export async function chatStream(
  payload: ChatRequest,
  onEvent: (event: string, data: any) => void
): Promise<void> {
  const res = await fetch("http://127.0.0.1:8000/api/chat/stream", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Accept: "text/event-stream",
    },
    body: JSON.stringify(payload),
  });

  if (!res.body) throw new Error("No response body");

  const reader = res.body.getReader();
  const decoder = new TextDecoder();
  let buffer = "";

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });

    const parts = buffer.split("\n\n");
    buffer = parts.pop() || "";

    for (const part of parts) {
      const lines = part.split("\n");
      const event = lines
        .find((l) => l.startsWith("event:"))
        ?.slice(6)
        .trim();
      const data = lines
        .find((l) => l.startsWith("data:"))
        ?.slice(5)
        .trim();

      if (event && data) {
        onEvent(event, JSON.parse(data));
      }
    }
  }
}
```

### 4.2 调用示例

```ts
await chatStream(
  {
    conversation_id: null,
    question: "心肌细胞动作电位分几期？",
    top_k: 6,
  },
  (event, data) => {
    if (event === "meta") {
      currentConversationId.value = data.conversation_id;
    } else if (event === "sources") {
      sources.value = data.sources;
    } else if (event === "delta") {
      answer.value += data.content;
    } else if (event === "done") {
      loading.value = false;
    } else if (event === "error") {
      errorMsg.value = data.message;
      loading.value = false;
    }
  }
);
```

## 5. 后端接口实现骨架（FastAPI）

```python
# app/api/chat.py
from fastapi import APIRouter
from sse_starlette.sse import EventSourceResponse

router = APIRouter(prefix="/api/chat", tags=["chat"])

@router.post("/stream")
async def chat_stream(payload: ChatRequest):
    async def event_generator():
        # 1. 推送 meta
        yield {
            "event": "meta",
            "data": json.dumps({"conversation_id": cid, "message_id": mid}),
        }
        # 2. 检索 + 推送 sources
        sources = retrieve(payload.question, payload.top_k)
        yield {
            "event": "sources",
            "data": json.dumps({"sources": [s.dict() for s in sources]}),
        }
        # 3. 流式生成
        async for token in generate(payload.question, sources):
            yield {
                "event": "delta",
                "data": json.dumps({"content": token}),
            }
        # 4. 结束
        yield {
            "event": "done",
            "data": json.dumps({"message_id": mid, "finish_reason": "stop"}),
        }

    return EventSourceResponse(event_generator())
```

## 6. 接口开发顺序建议

1. `/api/health` — 验证服务能跑
2. `/api/documents` + `/api/documents/ingest` — 验证入库
3. `/api/chat/stream` — 先返回假 SSE，跑通前后端联调
4. 接入真实 RAG（检索 + LLM）
5. `/api/conversations` 系列 — 会话历史
6. `/api/feedback` — 反馈

---

## 7. 字段命名规范

- 所有字段用 `snake_case`
- 前端 TypeScript 类型定义与后端保持一致
- 时间统一用字符串，不用时间戳
- 布尔值统一用 `true` / `false`，不用 0 / 1
