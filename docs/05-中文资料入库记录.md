## 入库和检索核对

四本资料已加入 `backend/app/data/books/`，对应同名 JSON 保存中文书名、作者、来源、许可证和链接。已有三本 Open RN 英文教材仍在库中；最终共 7 本、4,335 页、13,711 个片段，BGE 索引全部就绪。

首次增量入库完成后，重启检查发现另一次重建已被中断，向量集合为空、文档状态不完整；随后恢复全部索引，并等待完成再做验收。独立新进程重新打开正式向量存储，确认 13,711 个向量、逐书片段数以及逐书原生向量查询均可用，检查过程未修改向量。

`eval/chinese-book-questions.json` 的 8 个问题及原文锚点在检索前从 PDF 独立核对。`scripts/verify_chinese_books.py` 通过运行中的本地 API 检查：

- 每本书限定范围的 8 个中文问题：返回前三条片段中，预期物理页命中 8/8。
- 七本资料全库检索同样 8 个问题：预期书及物理页命中 7/8。风险两个要素的问题返回了同书其他页，严格的预期页判定未通过，保留该结果。
- 16 次检索返回的 48 条来源，文件指纹、单页范围和原文片段映射全部核对。
- 本次本地原文摘录响应为 30–366 ms；该时间不是 DeepSeek 生成性能验收。
- 临时验证会话在检查后清理，仅删除本次脚本自己创建的会话。

完整的无全文片段摘要保存在 `eval/chinese-retrieval-benchmark.json`。

定义题原先容易被正文中的高频术语挤出前三条来源；现对明确请求的术语定义及较长查询的完整词覆盖优先排序，仍保留弱相关过滤与原文引用。新增了定义题回归检查；20 项后端测试及 Vue TypeScript / 生产构建通过。原有三本英文教材的独立基准复测：10/10 预期页召回、9/10 首条预期页命中、3 个教材外拒答和追问检索通过。

## 页面与使用

三本 WHO 生物安全中文手册就绪后，首页自动显示中文示例问题。来源面板仍展示书名、PDF 物理页、片段和许可；中文原页预览的 HTML、PNG 及文件指纹检查通过。双击 `download-chinese-books.cmd` 可在其他电脑下载这些资料、启动服务并增量入库；下载脚本校验指纹、页数、许可文字及可检索中文，已有不同内容的同名文件不会被覆盖。

此次仍未配置 DeepSeek 密钥，只验证原文摘录、中文检索和原页映射，没有以摘录模式代替生成答案准确率、真实多轮生成、生成耗时或 API 账单验收。
