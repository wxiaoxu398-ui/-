# MedRAG 参赛完善与演示

记录日期：2026-11-10。参考 [AI WEB 网页开发挑战赛赛道说明](https://www.boxuegu.com/matchTrack/detail/?id=10037)。本文件将赛道要求对应到 MedRAG 的实现、验证与提交材料；功能计划和历史测试均保留其适用范围，完成状态以本轮验收记录为准。

## 1. 作品定位与评审对应

MedRAG 面向医学生复习与教材阅读：把问题连接到导入资料中的原文、书名和物理页码，并在依据不足时拒答。选题对应赛道中的 RAG 知识问答与 AI 教育学习方向。按原需求继续在本机运行，服务绑定 `127.0.0.1`；官网将公网演示列为可选加分项。

| 评审维度 | 官网权重 | MedRAG 可展示的内容 | 需要保留的证据 |
| --- | ---: | --- | --- |
| AI 技术深度 | 35% | 混合检索、上下文追问、证据限定生成、逐句引用校验、拒答与中断处理 | 检索及提示词实现、SSE 事件、真实回答与失败案例 |
| 创新性 | 25% | 将教材问答、学习整理与原页核对串成学习过程；历史引用绑定文件指纹 | 学习模式演示、引用到原页操作、文件替换后的处理 |
| 前端工程质量 | 10% | Vue 3 / TypeScript 组件、Pinia 状态管理、流式响应与移动布局 | 构建结果、组件结构、桌面与窄屏检查 |
| 实用性 | 10% | 有明确使用者与合法资料，支持文档筛选、多轮学习和会话保存 | 教材内问题、追问、刷新后历史保留 |
| 用户体验 | 10% | 可发现的 API 配置、真实处理状态、引用点击、停止生成与错误反馈 | 连贯演示、加载与错误状态、键盘及窄屏操作 |
| 社会价值与商业潜力 | 10% | 面向学习场景减少无来源回答，支持可追溯与可复核阅读 | 用户场景、使用边界、资料许可和成本测量 |

AI 深度的细分项还涉及 Agent / 工作流、多模态以及 MCP / 工具集成。本项目已有的检索和生成流程应按实际实现解释；流程状态显示不构成自主 Agent，未实现的多模态、MCP 或 Function Calling 不列为已实现能力。评分由赛事评审决定，本文件不估算获奖概率。

尚未完成逐条医学结论的人工语义核验，引用准确率仍未知，不能宣称已达到 80%。检索未命中的第 4 题保留原有独立标准，没有根据本轮结果改写预期页。新增学习流程属于确定性 RAG 工作流，不称为自主 Agent；未实现的多模态和 MCP 能力不计为完成。

## 4. 六分钟演示分镜

官网要求 5–8 分钟 MP4、至少 1080p、普通话讲解，可配字幕。下面安排为 6 分钟；应使用提交版本与实际可用的资料，录制前先完成一次独立试运行。

| 时间 | 画面与操作 | 讲解要点 |
| --- | --- | --- |
| 00:00–00:40 | 打开作品说明与学习主界面 | 医学生复习中如何核对答案出处；本工具用于医学学习 |
| 00:40–01:15 | 文档库、一本中文手册的来源和许可 | 资料来自哪里、覆盖什么、如何导入与建立索引；无需现场全量重建 |
| 01:15–02:10 | 提问“教材如何定义生物安全”，点击引用再打开原页 | 展示真实流式回答、片段、物理页与原书之间的对应关系 |
| 02:10–03:00 | 围绕同一主题切换知识梳理或自测，再做一次追问 | 学习输出仍依赖本轮证据，追问携带上下文 |
| 03:00–03:40 | 问一个资料外问题；展示停止或错误反馈 | 说明拒答与兜底；录制中若出现真实失败，应如实解释 |
| 03:40–04:20 | 切换历史会话、刷新恢复、导出 Markdown | 学习过程在本机保存，引用仍可核对 |
| 04:20–05:20 | 质量评估页，展示真实教材题集及人工审阅样本 | 区分页命中和引用准确率；展示耗时、拒答与结果导出 |
| 05:20–06:00 | 作品说明中的架构、创新点与限制 | 解释 BGE + BM25 + RRF、引用校验、文件指纹；交代当前验证范围与后续方向 |

耗时较长的评估可在录制前运行并明确展示运行时间与保存结果；已有结果不描述为当场生成。屏幕录制避开密钥输入、个人账号、无关历史与私人资料。

## 6. 技术 PDF 建议结构

建议将正文控制在 20–24 页，另留排版余量，并在导出后检查总页数与中文显示。

| 部分 | 应说明的内容 |
| --- | --- |
| 项目概述与需求 | 医学生学习场景、问题定义、范围、资料与许可 |
| 系统架构 | Vue / Pinia 前端、FastAPI、SQLite、Chroma、PDF 处理及 DeepSeek 调用边界 |
| AI 技术方案 | 选型理由、分块、混合检索与融合、上下文、证据提示词、引用与拒答约束 |
| 核心实现 | 流式事件、学习模式、原页追溯、停止生成、历史、评估与导出 |
| 测试与运行 | 环境和版本、自动化测试、真实教材题集、人工引用核验、实际耗时及用量 |
| 创新点与价值 | 只讨论已有实现的技术组合、学习交互、可复核性与适用人群 |
| 限制与展望 | 当前教材覆盖、检索漏召回、语义引用仍需人审、模型波动与成本边界 |

关键实现应能在代码与演示中找到对应位置。涉及第三方组件、开放资料和 AI 辅助开发的部分应如实说明；赛事所要求的原创性与授权情况由参赛团队确认。
