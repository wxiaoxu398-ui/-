# MedRAG 复现与提交指南

## 材料包与仓库的关系

源码 ZIP 便于查看当前文件；Git bundle 用于保留完整的当前分支开发历史。二者都不能代替官网要求的 GitHub/Gitee 仓库及评审访问权限。

用户提供的 `https://github.com/new` 是创建入口，尚不是具体仓库地址。建议仓库名 `MedRAG`；描述可用“面向医学生的本地医学教材 RAG 学习助手，支持原页引用、知识梳理、自测与评估”。公开可见或评审授权方式应由团队确认。不要将报名团队页、学生证件、密钥或实际会话历史公开上传。

源码只跟踪 `submission/team-info.example.json` 空模板，真实 `team-info.json` 在本机忽略；本地交付包会保留这份待填信息，供你核对，不能直接当作对外上传清单。

## 从历史包恢复

先解压总材料包，在 `01-源码` 目录执行：

```powershell
git clone .\MedRAG-history.bundle MedRAG
cd .\MedRAG
git log --oneline
```

如果 bundle 中未指定默认开发分支，可按打包清单记录的归档提交号切换到该提交；不要删除真实开发历史再重新初始化仓库。

## 在另一目录或电脑运行

1. 安装 Python 3.11-3.13、Node.js 20.19+ 和 Git；当前开发记录主要来自 Windows / Python 3.12，完整跨电脑冷启动仍需团队再验。
2. 克隆历史包或解压源码 ZIP，双击 `start-medrag.cmd`。首次会联网安装依赖并构建网页；本地只绑定 `127.0.0.1:8000`。
3. 准备有使用权限的文字 PDF。可运行 `download-chinese-books.cmd` 下载四份中文学习资料并增量入库，或运行 `download-demo-books.cmd` 下载三本 Open RN 英文教材后入库。完整英文资料下载量较大。
4. 首次 BGE 使用需要联网获取模型；遇到模型下载或网络问题，先核对日志与缓存。网页设置中的 BM25 轻量模式会改变检索方式，需要重新建立索引，不能混用旧向量结果。
5. 在网页右上角填写自己的 DeepSeek API Key 并保存；无密钥时只展示原文摘录。`.env.example` 是空模板，实际密钥不随材料包分发。
6. 提问“教材如何定义生物安全”，点击引用核对原页，再测试一次上下文追问和资料外拒答。确认刷新后历史可恢复、笔记可导出。
7. 可运行 `.venv\Scripts\python.exe -m pytest backend/tests -q` 检查隔离测试。真实问答会使用配置的 API，消耗额度；不要把软件夹具测试说成医学正确性证明。
8. 所有资料齐备后录制提交版本的视频，保存实际结果与记录时间。当前截图和评估是原开发环境快照，另一环境资料数和耗时可能不同。

## 创建评审仓库的建议步骤

1. 在 GitHub/Gitee 创建真实仓库，确认账号、仓库名和访问方式。保留已有 Git 历史；创建空仓库时不要引入冲突的初始 README。
2. 依据平台显示的实际仓库地址设置 `origin`；`github.com/new` 不能填入 `git remote add`。
3. 上传前复查待提交文件。包中排除了真实 `.env`、数据库、用户会话、模型缓存、PDF 教材、依赖目录和构建缓存。
4. 推送开发分支并设置适合评审的默认分支；公开仓库或私有仓库的评审授权均须在提交前确认。
5. 将真实仓库 URL 写入团队信息、README、技术文档及官网表单；项目的许可方式与第三方声明由团队确认，本次没有替团队选择开源许可证。

## 官网提交前

- 补齐真实队名、学校、组别、成员和分工；建议分工不是已完成贡献证明，也不替代报名系统记录。
- 核对技术 PDF 的团队信息、页数和最终版本，再生成一份新的材料包和校验清单。
- 加入合格的讲解 MP4；脚本、截图和源文件均不能作为视频成片替代。
- 使用报名账户核实比赛轮次、报名/缴费状态和作品入口，再按官网逐项上传。当前公开省赛页列出 2026-11-18，具体轮次和后续通知以个人中心为准。
- 确认实际提交成功并保存回执。本材料包整理完成不等于已经报名或提交，当前 `127.0.0.1` 地址也不是可公网访问的在线演示。

## 修改并重生成技术 PDF

先将 `submission/team-info.example.json` 复制为 `submission/team-info.json` 并填写。PDF 制作工具独立于网页运行，使用 ReportLab、pypdf、Pillow；依赖见 `submission/requirements-docs.txt`。在 Windows 使用本机微软雅黑，其他系统可用 `--font` 和 `--bold-font` 指定支持中文的 TrueType 字体。

```powershell
python submission/render_technical_pdf.py --screenshots-dir "交付包中实际截图目录"
```

截图目录应含 `medrag-competition-study.png`、`medrag-competition-project.png`、`medrag-competition-mobile.png`；可使用本包 `04-验证与资料` 中的相应图片，或记录新版本的真实界面。修改后重新检查页数、目录、团队信息和所有页的版面，不沿用旧 PDF 的核验结论。
