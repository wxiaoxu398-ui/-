## 直接使用评审运行包

1. 将 `05-评审运行包/MedRAG-Review-20261111.zip` 完整解压到本机磁盘，保留整个文件夹结构。不要在压缩软件内直接打开 CMD，也不要只复制启动文件。
2. 双击解压目录的 `check-medrag.cmd` 检查环境，再双击 `start-medrag.cmd`。使用 Chrome 或 Edge，网页地址为 `http://127.0.0.1:8000/`；它只对当前电脑有效。首次加载较慢，请保留启动窗口等待，默认最多等待 300 秒。本机已记录首次约 139.31 秒、再次冷启动约 35.62 秒，不能据此承诺所有电脑耗时相同。
3. 该包自带 Python 3.12、依赖、已构建网页、模型与公开教材索引，日常启动不需要 Node.js。若 8000 端口被其他软件占用，请先确认并关闭占用软件；启动器不会结束未知程序。双击 `stop-medrag.cmd` 停止本目录服务。
4. 离线可使用本地检索与原文摘录。DeepSeek 生成解释、知识梳理、自测需要可用网络与自己的 API Key，在网页右上角 API 设置中配置。真实密钥不随交付包分发，也不要录入视频或公开仓库。
5. 记录包内资料来源及许可。运行包内的 README 和材料是构建时快照；本次正式队伍、指导老师、分工和最新技术说明，以总材料包中的文件为准。原运行 ZIP 保持原样，外置清单记录实际 SHA、体积及核验范围。

```powershell
git clone https://github.com/wxiaoxu398-ui/-.git MedRAG
cd MedRAG
git log --oneline --decorate -12
```

源码 ZIP 与历史 bundle 均不包含运行时、模型、教材原 PDF、数据库或真实密钥。纯源码环境需要 Python 3.11-3.13、Node.js 20.19+ 和网络：先双击 `prepare-medrag.cmd` 安装依赖、构建网页并准备模型，再双击 `start-medrag.cmd`。教材可用根目录下载脚本获取，建立索引后提问。API Key 通过网页保存到本机，源码仅提供 `.env.example`。

历史备份可从总材料包 `01-源码` 目录恢复：


- 当前运行包已在同一台电脑的另一目录做离线启动检查；这不等于另一台实体电脑或真实 Windows 重启后已验证。

- 39 项隔离软件测试不能代替医学结论核验。原页命中、引用编号有效和引用语义正确分别记录。

## 修改材料与重新打包

公开团队资料使用 `submission/team-profile.json`，不含报名链接或编号。PDF 依赖见 `submission/requirements-docs.txt`，需支持中文的字体。保留原运行 ZIP，打包参数与实际页数对应：

```powershell
python submission/render_technical_pdf.py --date 2026-11-11 --implementation-commit b8c593f
python submission/build_package.py --date 20261111 --pdf-pages ACTUAL_PAGE_COUNT --implementation-commit b8c593f --review-archive .local/input/MedRAG-Review-20261111.zip
```

将 `ACTUAL_PAGE_COUNT` 替换为重新渲染并检查的实际页数，PDF 必须不超过 30 页。输出目录不得覆盖旧包。若还要记录远端核验，先正常推送，再以实际 `git ls-remote` 读取的完整 SHA 使用 `--repository-verified-commit`；实际通过未登录读取后才加 `--repository-public-read-verified`，打包脚本不会自行联网证明这些状态。
