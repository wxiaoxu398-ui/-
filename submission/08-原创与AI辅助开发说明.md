## 项目实现与开发记录

MedRAG 围绕教材学习实现资料管理、三栏问答、网页 API 配置、BGE/BM25/RRF 混合检索、证据限定生成、引用格式检查、原页追溯、拒答、知识梳理、自测、会话与评估导出，以及 Windows 启动和评审运行包。源码位于 `frontend/src/`、`backend/app/` 和 `scripts/`，真实开发过程保留在 Git 历史中。项目使用既有基础算法与组件，不主张这些算法、模型或通用功能具有学术首创性。

## AI 辅助与生成内容

开发和材料整理使用 OpenAI Codex 辅助，涉及需求梳理、代码与界面修改、排障、检查脚本、技术报告和提交材料。团队需能够理解并解释实际提交的实现；个人贡献以真实协作、提交记录和本人说明为依据。当前成员分工为本次确定的职责安排，不据此编造历史工时或贡献比例。

应用通过 DeepSeek API，依据本轮教材片段组织解释、梳理和自测；输出仍需对照原文核验。原页命中与引用语义正确分别统计，固定中文评测的人工语义核验保持 0 条、准确率未知。`07-引用语义人工复核表.md` 为人工审阅提供工作表，自动摘要不计入人审。

演示采用真实浏览器操作及普通话合成配音，配音来源和媒体规格见视频核验记录；合成语音不标作成员本人录音。实际成片状态以最终包清单为准。
