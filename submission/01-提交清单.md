# MedRAG 参赛提交清单

核对日期：2026-11-10。要求来源：[AI WEB 网页开发挑战赛官方赛道页](https://www.boxuegu.com/matchTrack/detail/?id=10037)。

本清单将官网必交材料、需要团队补充的信息、质量复核和可选项分别列出。源码压缩包、Git 历史备份和演示脚本便于交接，不能替代远程代码仓库、讲解视频或官网提交记录。

用户补充的团队参考页及编号已记录在本机 `team-info.json`，该文件不进入源码版本。目前未能据此确认实名成员、学校、组别或指导老师。用户提供的 [GitHub 创建入口](https://github.com/new) 用于新建仓库，不是已经建立的项目仓库地址。

## 二、还需要团队补充或确认的内容

1. **真实团队资料**：根据团队页核实队名、学校、参赛组别、1-3 位同校成员及分工；指导老师如有则填写，最多 2 位。新克隆时复制 `team-info.example.json` 为本机 `team-info.json`，填写后同步到 README、技术 PDF 封面和视频片头；删除未使用的成员或教师空行。下面的建议队名及分工不能当成真实报名信息。
2. **评审可访问的仓库**：在 GitHub 创建入口建立或指定实际项目仓库，再填写项目地址、上传完整历史并核实权限。当前只有本地仓库，不把创建入口或备份包标为“已托管”。
3. **讲解视频成品**：六分钟分镜已准备，但仍需录制、配普通话讲解并导出合格 MP4；截图和脚本文档不算视频成品。
4. **技术 PDF 的团队终审**：PDF 生成后确认页数不超过 30 页、团队字段完整、界面截图和实现一致，核对引用及测试表述。文档制作完成不等于团队已确认内容。
5. **实际提交状态**：确认个人中心的报名、缴费、轮次和入口信息，按通知上传材料并保存回执。本项目未代为报名、缴费或对外提交。

## 四、官网可选项

**公网在线演示**为可选加分项。本项目按原需求继续仅在本机运行，没有公网部署；`http://127.0.0.1:8000/` 仅供当前电脑使用，不是公开演示地址。若不选择公网演示，仍需准备完整的源码、视频和 PDF，并按赛事流程提交。

- [ ] 源码与历史备份均不含真实密钥、个人会话、数据库和本机缓存；忽略规则不能替代实际打包核查。
- [ ] 提交材料使用已验证版本，保留真实失败、性能和未人工核验的边界说明。
- [ ] 最终轮次、时间和入口已按个人中心通知确认，上传后保留回执。
